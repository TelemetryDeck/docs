## Introduction

Accessibility Parameters provide information about the user’s accessibility device settings to help make apps more inclusive.

## Parameters

**Name**: `TelemetryDeck.Accessibility.isReduceMotionEnabled`</br>
**Type**: Bool</br>
**Description**: Clarifies whether Reduce Motion is enabled.

**Name**: `TelemetryDeck.Accessibility.isBoldTextEnabled`</br>
**Type**: Bool</br>
**Description**: Shows whether Bold Text is enabled.

**Name**: `TelemetryDeck.Accessibility.isInvertColorsEnabled`</br>
**Type**: Bool</br>
**Description**: Shows whether Invert Colors is enabled.

**Name**: `TelemetryDeck.Accessibility.isDarkerSystemColorsEnabled`</br>
**Type**: Bool</br>
**Description**: Shows whether Darker System Colors are enabled.

**Name**: `TelemetryDeck.Accessibility.isReduceTransparencyEnabled`</br>
**Type**: Bool</br>
**Description**: Shows whether Reduce Transparency is enabled.

**Name**: `TelemetryDeck.Accessibility.shouldDifferentiateWithoutColor`</br>
**Type**: Bool</br>
**Description**: Shows whether UI should differentiate without color.

**Name**: `TelemetryDeck.Accessibility.preferredContentSizeCategory`</br>
**Type**: String</br>
**Description**: Shows User’s preferred text size category (e.g. L, XXL).
