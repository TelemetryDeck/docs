## Introduction

App Info Parameters provide information about the specific app build, such as version, build number, or SDKs compiled with.

## Parameters

**Name**: `TelemetryDeck.AppInfo.buildNumber`</br>
**Type**: String</br>
**Description**: The build number of the app.

**Name**: `TelemetryDeck.AppInfo.version`</br>
**Type**: String</br>
**Description**: The version of the app.

**Name**: `TelemetryDeck.AppInfo.versionAndBuildNumber`</br>
**Type**: String</br>
**Description**: The version and build number of the app, separated by a space.
