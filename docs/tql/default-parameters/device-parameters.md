## Introduction

Device Parameters provide information about the device running the application, such as operating system, model name, or architecture.

## Parameters

**Name**: `TelemetryDeck.Device.architecture`</br>
**Type**: String</br>
**Description**: The architecture of the device.

**Name**: `TelemetryDeck.Device.modelName`</br>
**Type**: String</br>
**Description**: The model name of the device.

**Name**: `TelemetryDeck.Device.operatingSystem`</br>
**Type**: String</br>
**Description**: The operating system of the device.

**Name**: `TelemetryDeck.Device.orientation`</br>
**Type**: String</br>
**Description**: The orientation of the device.

**Name**: `TelemetryDeck.Device.platform`</br>
**Type**: String</br>
**Description**: The platform of the device.

**Name**: `TelemetryDeck.Device.screenResolutionHeight`</br>
**Type**: Double</br>
**Description**: The height of the screen in points.

**Name**: `TelemetryDeck.Device.screenResolutionWidth`</br>
**Type**: Double</br>
**Description**: The width of the screen in points.

**Name**: `TelemetryDeck.Device.screenScaleFactor`</br>
**Type**: Double</br>
**Description**: The scale factor to calculate pixels from points (e.g. 2.0 for Retina).

**Name**: `TelemetryDeck.Device.systemMajorMinorVersion`</br>
**Type**: String</br>
**Description**: The major and minor version of the operating system.

**Name**: `TelemetryDeck.Device.systemMajorVersion`</br>
**Type**: String</br>
**Description**: The major version of the operating system.

**Name**: `TelemetryDeck.Device.systemVersion`</br>
**Type**: String</br>
**Description**: The version of the operating system.

**Name**: `TelemetryDeck.Device.timeZone`</br>
**Type**: String</br>
**Description**: The time zone of the device i.e. for example ‘UTC+1’.

**Name**: `TelemetryDeck.Device.screenDensity`</br>
**Type**: Double</br>
**Description**: The screen density of the device.

**Name**: `TelemetryDeck.Device.brand`</br>
**Type**: String</br>
**Description**: The brand of the device.
