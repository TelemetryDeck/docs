## Introduction

The following parameters provide information related to the integration of RevenueCat into TelemetryDeck.

## Parameters

**Name**: `RevenueCat.event.commission_percentage`</br>
**Type**: Double</br>
**Description**: Provides information of the commission percentage.

**Name**: `RevenueCat.event.price`</br>
**Type**: Double</br>
**Description**: The price related to the event triggered.

**Name**: `RevenueCat.event.price_in_purchased_currency`</br>
**Type**: Double</br>
**Description**: The price related to the event triggered in original currency.

**Name**: `RevenueCat.event.takehome_percentage`</br>
**Type**: Double</br>
**Description**: Provides information how much percent of the purchase is actually received.

**Name**: `RevenueCat.event.tax_percentage`</br>
**Type**: Double</br>
**Description**: Provides information of the tax percentage.
