## Introduction

SDK Parameters provide information about the TelemetryDeck SDK, such as its name or version number.

## Parameters

**Name**: `TelemetryDeck.SDK.name`</br>
**Type**: String</br>
**Description**: The name of the SDK.

**Name**: `TelemetryDeck.SDK.version`</br>
**Type**: String</br>
**Description**: The version of the SDK.

**Name**: `TelemetryDeck.SDK.nameAndVersion`</br>
**Type**: String</br>
**Description**: The name and version of the SDK, separated by a space.

**Name**: `TelemetryDeck.SDK.buildType`</br>
**Type**: String</br>
**Description**: The build type of the SDK.
