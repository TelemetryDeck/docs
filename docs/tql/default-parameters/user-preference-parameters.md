## Introduction

User Preference Parameters provide information about the user's preferences, such as language and region.

## Parameters

**Name**: `TelemetryDeck.UserPreference.colorScheme`</br>
**Type**: Enum</br>
**Description**: Dark or Light, depending on the user preference.

**Name**: `TelemetryDeck.UserPreference.language`</br>
**Type**: String</br>
**Description**: The preferred language of the user according to the device settings.

**Name**: `TelemetryDeck.UserPreference.layoutDirection`</br>
**Type**: Enum</br>
**Description**: leftToRight or rightToLeft, based on user preference.

**Name**: `TelemetryDeck.UserPreference.region`</br>
**Type**: String</br>
**Description**: The preferred region of the user according to the device settings.
