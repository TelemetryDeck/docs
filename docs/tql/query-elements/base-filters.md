## Introduction

Base Filters specify default filters to be attached to a query before executing it. The filters generated by this rule are combined with a query's filter property using an and-filter. The default value for baseFilters is thisOrganization.

## Specifics & Examples

Following you can find information regarding the different Base Filters available and examples of their application.

**Name**: `thisOrganization`

**Explanation**: A filter for all apps of the executing user's organization, i.e. not only the data of the current app is considered. This is the default value.

**Example**:

```
{
    "baseFilters": "thisOrganization"
}
```

**Property Reference**

**Property**: `baseFilters`</br>
**Description**: baseFilters applied to a query, defaults to 'thisOrganization'.</br>
**Required**: false

---

**Name**: `thisApp`

**Explanation**: A filter for a specific app the insight lives in. If the query does not belong to a dashboard of an app, this value requires the query's appID property to be set.

**Example**:

```
{
    "baseFilters": "thisApp",
    "appID": "<add appID here>"
}
```

**Property Reference**

**Property**: `baseFilters`</br>
**Description**: baseFilters applied to a query, defaults to 'thisOrganization'. Can be changed to 'thisApp' to only use data of a specific app.</br>
**Required**: false

**Property**: `appID`</br>
**Description**: appID of the app the data shall be used from (can be found under 'Setup' in the UI). The property is only available if baseFilters is 'thisApp'.</br>
**Required**: false
